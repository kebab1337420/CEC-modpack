Texture-sonde UV pour les Cloakers.

Grille 8x8, cases A1 (haut-gauche) a H8 (bas-droite).
Lancer le jeu, croiser un Cloaker, prendre une capture de face et de dos.
Les cases lisibles sur le torse donnent la zone UV a viser.

Le mod chien est mis de cote dans assets/mod_overrides_off/ pendant ce temps.
